# Цех — учет складских остатков

Система учета продукции на нескольких складах и у торговых представителей.

## Цели первой версии

- остатки по нескольким складам в реальном времени;
- две цены товара: розничная и оптовая;
- выдача товара торговому представителю с уменьшением остатка склада и постановкой товара на остаток представителя;
- учет продаж и сдачи денежных средств торговым представителем;
- списание проданного товара с остатка представителя;
- возврат товара от торгового представителя на склад;
- перемещение товара между складами;
- роли: торговый представитель, администратор, руководитель;
- журнал всех движений товара и денег;
- API для последующей интеграции с 1С.

## Архитектура

Репозиторий организуется как монорепозиторий:

- `backend/` — REST API, WebSocket-уведомления, бизнес-логика, PostgreSQL;
- `android/` — Android-приложение торгового представителя на Kotlin + Jetpack Compose;
- `admin-web/` — веб-панель администратора и руководителя;
- `docs/` — архитектура, API и правила интеграции с 1С.

## Базовые принципы учета

Остатки не редактируются напрямую. Любое изменение фиксируется документом движения и проводками по товару. Это позволяет восстановить историю, избежать расхождений и безопасно синхронизироваться с 1С.

Денежные операции торгового представителя ведутся отдельным регистром: продажа увеличивает его задолженность перед компанией, сдача денег уменьшает задолженность.

## Технологический стек

- Backend: Python 3.12, FastAPI, SQLAlchemy 2, Alembic, PostgreSQL, Pydantic;
- Real-time: WebSocket;
- Android: Kotlin, Jetpack Compose, Retrofit/OkHttp, Room;
- Web: React + TypeScript;
- Инфраструктура разработки: Docker Compose.

## Статус

Проект находится в активной разработке. Первый этап — серверное ядро учета, схема данных и API, затем Android-клиент и панель управления.
