# API первой итерации

Базовый адрес: `/api/v1`.

- `GET /products` — товары и две цены;
- `GET /locations` — склады и виртуальные склады представителей;
- `GET /stocks?location_id=...` — остатки;
- `POST /stock/transfers` — перемещение склад ↔ склад;
- `POST /stock/issue-to-representative` — выдача торговому представителю;
- `POST /stock/representative-return` — возврат от представителя;
- `POST /sales` — продажа с розничной или оптовой ценой;
- `POST /cash-handovers` — сдача денег;
- `GET /representatives/{id}/debt` — текущая задолженность;
- `WS /realtime` — уведомления об изменении остатков.

Интерактивная документация FastAPI после запуска: `/docs`.

> В текущей итерации API является каркасом бизнес-функций. Авторизация и ограничения по ролям должны быть добавлены до эксплуатации с реальными данными.
