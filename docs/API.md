# API первой итерации

Базовый адрес: `/api/v1`.

## Авторизация

- `POST /auth/login` — получить Bearer JWT по логину и паролю;
- `GET /auth/me` — текущий пользователь и роль;
- `POST /auth/change-password` — сменить собственный пароль, указав текущий и новый;
- `POST /admin/users/{user_id}/reset-password` — администратор задает пользователю новый пароль.

Новый пароль должен содержать не менее 10 символов, включая буквы и цифры, не должен совпадать с логином и не должен быть одним из явно запрещенных распространенных вариантов.

JWT содержит отпечаток текущего Argon2-хэша пароля. После самостоятельной смены или административного сброса пароля все ранее выданные REST- и новые WebSocket-сессии пользователя становятся недействительными и требуют повторного входа.

Все бизнес-методы требуют `Authorization: Bearer <token>`. Торговый представитель серверно ограничен собственным виртуальным складом для продаж, возвратов, сдачи денег и задолженности. Остатки обычных складов доступны ему для просмотра.

## Справочники администратора

- `POST /admin/locations` — создать склад или виртуальный склад представителя;
- `POST /admin/products` — создать товар с розничной и оптовой ценой;
- `GET /admin/users` — список пользователей;
- `POST /admin/users` — создать пользователя и назначить роль;
- `POST /admin/users/{user_id}/reset-password` — сбросить пароль пользователя и инвалидировать его старые сессии;
- `POST /stock/adjustments` — провести начальный остаток или корректировку с обязательным комментарием.

## Остатки и операции

- `GET /products` — товары и две цены;
- `GET /locations` — склады и разрешенные пользователю места хранения;
- `GET /stocks?location_id=...` — остатки;
- `POST /stock/transfers` — перемещение склад ↔ склад, роль `admin`;
- `POST /stock/issue-to-representative` — выдача торговому представителю, роль `admin`;
- `POST /stock/representative-return` — возврат от представителя;
- `POST /sales` — продажа с розничной или оптовой ценой;
- `POST /cash-handovers` — сдача денег;
- `GET /representatives/{id}/debt` — текущая задолженность;
- `GET /representatives/debts/all` — задолженность всех представителей для администратора/руководителя;
- `WS /realtime?token=...` — уведомления об изменении остатков.

Интерактивная документация FastAPI после запуска: `/docs`.

Для локальной разработки первый администратор может быть создан переменными `BOOTSTRAP_ADMIN_LOGIN` и `BOOTSTRAP_ADMIN_PASSWORD`. В production bootstrap-логин и пароль задаются только вместе, пароль должен иметь не менее 12 символов. `JWT_SECRET` должен иметь не менее 32 символов; если включена интеграция с 1С, ее ключ также должен иметь не менее 32 символов. Production CORS допускает только HTTPS origins.
