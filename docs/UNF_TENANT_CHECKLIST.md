## Если это 1С:Фреш

Для приложений на `1cfresh.com` стандартный OData публикуется по адресу:

`<URL приложения>/odata/standard.odata/`

Первую проверку выполняйте только read-only probe из `unf-bridge`:

```bash
export UNF_FRESH_URL='https://1cfresh.com/a/.../...'
export UNF_FRESH_LOGIN='service-user'
export UNF_FRESH_PASSWORD='***'
ceh-unf-fresh-probe
```

Команда читает `$metadata`, не создает и не проводит документы и не печатает пароль. В релизный журнал сохраняются только URL без credentials, версия УНФ и найденные EntitySet, необходимые для сопоставления.

После probe нужно отдельно зафиксировать фактические EntitySet/реквизиты для:

- номенклатуры;
- складов;
- организации;
- контрагентов;
- перемещения запасов;
- расходной накладной;
- поступления в кассу;
- оприходования и списания запасов.

До получения metadata конкретного tenant эти имена в production-конфигурацию не зашиваются.
